# KPI 평가 · 연봉인상 시스템

엑셀 평가지(`2025년 4분기 평가지.xlsx`)로 운영하던 **KPI 평가와 연봉인상률 산출**을 웹 도구로 옮긴 프로젝트입니다.
팀 실적과 개인 평가를 입력하면 등급, 연봉 수준, 인상률, 인상 연봉이 자동으로 계산됩니다.

**▶ 데모: https://skdownsk-tech.github.io/kpi-evaluation/** (가상 인물 110명 데이터)
· [계산 엔진 테스트](https://skdownsk-tech.github.io/kpi-evaluation/app/tests.html)

## 실행 방법

설치할 것이 없습니다.

* **바로 열기**: `app/index.html`을 Chrome이나 Edge로 엽니다.
* **로컬 서버로 열기**: PowerShell에서 아래 명령을 실행한 뒤 http://localhost:8080 에 접속합니다.

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

처음 열면 가상 인물 110명으로 만든 데모 데이터가 나옵니다. **대상자 관리 → 엑셀에서 가져오기**로 실제 평가지의 `대상자` 시트를 불러올 수 있습니다.
엑셀 가져오기와 내보내기는 SheetJS를 CDN에서 불러오므로 인터넷 연결이 필요합니다. 오프라인에서는 CSV로 내보냅니다.

## 평가 로직

```
팀 달성률   = (팀 매출 달성률 + 팀 영업이익 달성률) ÷ 2          → 팀 등급 (E/V/G/N/P)
개인 점수   = 개인 KPI 점수(최종 → 부문장 → 본인) − 감점        → 개인 등급
종합 등급   = 팀 등급 × 개인 등급 매트릭스 (각 50%)
연봉 수준   = 현재연봉 ÷ 동종업계 직급별 평균연봉
산출 인상률 = 등급별 기본 인상률 σ + 연봉 수준 구간별 조정
            (P등급은 표의 값 그대로: 업계 평균보다 높은 연봉이면 −2% ~ −3% 삭감)
최종 인상률 = 부사장 조정값(사유 필수)이 있으면 그 값, 없으면 산출 인상률
```

구간표, 매트릭스, 엑셀에서 발견한 문제와 해석 방식은 [docs/DESIGN.md](docs/DESIGN.md)에 정리했습니다.
모든 기준값은 화면의 **평가 기준 설정**에서 바꿀 수 있습니다.

## 화면

| 화면 | 내용 |
|---|---|
| 대시보드 | 대상자 수, 산출 완료율, 평균 인상률, 인건비 증가액, 종합 등급 분포, 팀별 현황, 미입력 대상자 |
| 팀 평가 | 팀별 매출·영업이익 목표와 실적 입력 → 팀 달성률과 등급 |
| 개인 평가 | 본인·부문장·최종 평가와 감점요인 입력 → 개인, 팀, 종합 등급. 개인별 평가표 출력 |
| 연봉 인상 | 연봉 수준, σ, 조정값, 산출 인상률, 부사장 조정, 인상 연봉 |
| 대상자 관리 | 대상자 추가와 수정, 연봉체류일, 엑셀 가져오기 |
| 평가 기준 설정 | 등급 구간, 종합 매트릭스, 인상률표, 감점 기준, 업계평균 연봉, 백업과 복원 |

## 구조

```
app/
  index.html      화면 뼈대
  css/style.css   스타일 (라이트/다크 모드)
  js/engine.js    계산 엔진 — 화면과 분리된 순수 함수
  js/data.js      기본 기준값과 데모 데이터 생성
  js/app.js       화면 렌더링, 입력 처리, 엑셀 가져오기/내보내기
  tests.html      계산 엔진 테스트 (브라우저에서 열면 실행)
docs/DESIGN.md    엑셀 분석 결과와 설계
index.html        GitHub Pages 첫 화면 (app/으로 이동)
serve.ps1         설치 없이 쓰는 로컬 서버
```

## 테스트

`app/tests.html`을 브라우저로 열면 18개 테스트가 실행됩니다. 엑셀 평가지 샘플(과장2, 연봉 46,000,080원 → 연봉 수준 95.34%, G등급 7%, 인상 연봉 49,220,086원)을 그대로 재현하는지와 모든 구간 경계값을 확인합니다.

## 데이터와 개인정보

* 저장소에는 가상 인물로 만든 데모 데이터만 들어 있습니다.
* 입력하거나 가져온 데이터는 사용하는 브라우저의 저장소에만 저장되고 어디로도 전송되지 않습니다.
* 브라우저 데이터를 지우면 함께 사라지므로 **평가 기준 설정 → 백업 파일 저장**으로 백업해 주세요.
